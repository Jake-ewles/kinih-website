# Kinih Fitness & Coaching: Gym Website (Concept Project)

A multi-page website I designed and built for **Kinih Fitness & Coaching**, a fictional coached-fitness gym in Casablanca.
It's a portfolio project showing the kind of site I can build for a real local business.
It works in **English, French and Arabic** (with a full right-to-left layout), includes an in-browser FAQ chatbot, and has a demo member area.

🔗 **Live demo:** https://teal-moxie-5860a0.netlify.app/

## ✨ Features

- **3 languages: EN / FR / AR.** Every page switches language instantly, Arabic switches to a right-to-left layout, and the visitor's choice is remembered.
- **FAQ chatbot.** It runs entirely in the browser, answers questions about pricing, hours, programs and booking in the visitor's language (including common Darija words), and links to the right page.
- **Member area demo.** A sign-up flow leads to a personal dashboard (`membership.html` → `dashboard.html`) with the member's plan, workouts and simulated coach messages, all stored in the browser (no backend needed).
- **Conversion-focused pages.** Programs, coaches, client results, pricing and contact, with clear "Book a Free Assessment" and click-to-call buttons.
- **Smooth animations.** GSAP, scroll-reveal animations (AOS), smooth scrolling (Lenis), animated stat counters and a scrolling marquee.
- **Fully responsive.** Built mobile-first, so it works on phones, tablets and desktops.

> **Note:** Kinih is not a real business. The name, phone number, stats and testimonials are placeholder content I created for this project.

- [GSAP](https://gsap.com/) · [AOS](https://michalsnik.github.io/aos/) · [Lenis](https://lenis.darkroom.engineering/) · [Swiper](https://swiperjs.com/)
- Font Awesome icons · Google Fonts (Oswald, Inter, Tajawal for Arabic)

```bash
cd kinih-website

```
